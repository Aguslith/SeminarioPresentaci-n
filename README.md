# Seminario de Actualización - Desarrollo Web Moderno

Presentación interactiva creada con React, Vite, Framer Motion y Vanilla CSS para el seminario de actualización.

## Tecnologías explicadas
- HTML5, CSS3, JavaScript
- React
- Vite
- Node.js & NPM
- HTMX
- Ecosistema (Docker, Firebase, n8n, Rocky Linux)

## Cómo ejecutar localmente
1. Entra a la carpeta \`presentacion-web\`:
   \`\`\`bash
   cd presentacion-web
   \`\`\`
2. Instala las dependencias:
   \`\`\`bash
   npm install
   \`\`\`
3. Ejecuta el servidor de desarrollo:
   \`\`\`bash
   npm run dev
   \`\`\`
