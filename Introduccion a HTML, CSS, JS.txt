Agrega interacción

👉 Ejemplo básico:

<h1>Hola</h1>
<button onclick="saludar()">Click</button>

<script>
function saludar() {
  alert("Hola mundo");
}
</script>

}

🟢 5. Node.js (Backend)

👉 Sirve para:

Manejar datos
Procesar login
Conectar con base de datos
Ejemplo:
const http = require("http");

http.createServer((req, res) => {
  res.end("Hola desde servidor");
}).listen(3000);
